# 🍔 救命！我被麦麦包围了！

> 麦当劳程序员节创意开发大赛参赛作品 · 基于**麦当劳中国 MCP** 真实能力 · 用 **WorkBuddy** 开发
> 一个麦当劳版「沙威玛」模拟经营小游戏：你是被订单淹没的店员，限时手忙脚乱组装套餐、连击冲分。

---

## ✨ 这是什么

你是麦当劳门店里最惨的店员——顾客从四面八方涌来，每个人头顶都飘着一份订单（🍔+🍟+🥤）。
你要在倒计时归零前，从真实菜单里点出对应单品装进餐盘、交付出去。
连击越高分越多，但订单越堆越凶，**麦麦洪水**说来就来。忙到喊「救命」就对了。

- 🎮 **模拟经营 + 多线操作**：榜单里独一份的玩法（其余多为省钱/营养计算器、图鉴、动作生存）
- 🍟 **真实 MCP 数据底座**：菜单、活动单全部来自麦当劳官方 MCP（`query-meals` / `campaign-calendar`），每一单都是此刻真能买到的麦麦
- 📱 **单文件、零依赖、离线可玩**：纯 emoji 渲染，打开即玩，无需安装
- 🔒 **只读、零风险**：只读取展示，绝不点餐 / 领券 / 动账户

## 🕹 怎么玩

1. 顾客进场，气泡显示订单（如 🍔🍟🥤）
2. 点下方菜单把单品装进餐盘
3. 点「交付 ✅」比对队首顾客
4. 对了得分 + 连击；错了 / 超时扣血
5. 撑过 75 秒，看你能闯第几波、拿什么评级

**波次递进**：单品数 1→3、生成越来越快、第 6 波起出现「麦麦洪水」、限定活动单双倍分。

## 🚀 一键试玩

直接用浏览器打开 `index.html` 即可（演示菜单池，无需 Token）。

若用 **WorkBuddy + 麦当劳 MCP**，对 AI 说一句：

> 「开始麦麦包围」

AI 会先调用麦当劳 MCP 拉取**真实在售菜单与当前活动**，注入游戏——此时你玩到的每一单都是真实数据。

## 🧩 麦当劳 MCP 接入（真实调用）

| 工具 | 用途 |
|---|---|
| `query-meals` | 拉真实在售单品 → 菜单区与订单素材 |
| `campaign-calendar` | 当前有效活动 → 限定高分订单 |
| `query-meal-detail` | 订单单品卡片详情（可选） |

调用架构：**对话侧拉取 → 注入 `localStorage` → 游戏读取**，因此纯前端游戏无需持有 Token，既真实又安全。
详见 [`MCP_INTEGRATION.md`](./MCP_INTEGRATION.md) 与 [`skill/SKILL.md`](./skill/SKILL.md)。
